# Playwright 1.50 → 1.64.1

Date: 2026-10-28
Plan: inline (version bump)

## What changed
- `requirements.txt`, `controller_client/requirements.txt`: `playwright~=1.64.1`.
- `controller_client/browser_executor.py`: the `_NOT_INSTALLED_PATTERN` comment names 1.64.

## Why
Playwright 1.50 does not support Ubuntu 26.04 hosts. 1.64.1 does (`ubuntu26.04-x64` / `-arm64` in its browser registry).

## Behaviour and contract changes
- None in code. Test Runners must reinstall dependencies and browsers: `pip install -r requirements.txt`, then `playwright install --with-deps` (the setup scripts do both).

## Notes for future changes
- The three "not installed" launch errors matched by `_NOT_INSTALLED_PATTERN` were re-checked in the 1.64.1 driver and still match.
- No server code imports Playwright; the root pin only keeps the two requirement files in step.
