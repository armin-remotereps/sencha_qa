{# Re-run confirm #}

Re-run the selected cases?

The selected cases run again from step 1 on their run, in run order, keeping the run's help mode. Their log, screenshots and step progress are replaced; the previous result stays in each case's history. Checked marks are cleared. The run must be finished and its test machine ready.

{# Send confirm: the existing per-run send covers every checked, unsent case of each run #}

Send checked results to TestRail?

This sends all checked cases not yet sent of every run the selected cases belong to, not only the selected cases, exactly as "Send checked to TestRail" on the run page does. Selected cases that are not checked are not sent: check them first. Runs without TestRail settings, or still running, are reported and skipped.
