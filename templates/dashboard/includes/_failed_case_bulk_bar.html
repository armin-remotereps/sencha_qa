{# Re-run confirm #}

Re-run the selected cases?

The selected cases run again from step 1 on their run, in run order, keeping the run's help mode. Their log, screenshots and step progress are replaced; the previous result stays in each case's history. Checked marks are cleared. The run must be finished and its test machine ready.

{# Send confirm: checks and sends only the chosen failed cases, per run #}

Send the failed cases to TestRail?

This sends only these failed cases now, run by run, to the TestRail run each was imported from, also for runs still running. Cases that are not checked yet are marked checked by you. The failure screenshots are attached. Other cases of the same runs are not sent.
