Codex, Claude Code and the APIs

Use the same URL and send the project's Connection key (project Environment page) as a header:

Authorization: Bearer <connection key>

Every tool needs a project_id. Apps get it from the list_projects tool, also when a connection or key covers one project only.

Regenerating a project's Connection key also ends every ChatGPT and Claude connection's access to that project.
