{% comment %} Status badge for a TestRun. Context contract: status — TestRunStatus value: "waiting" | "started" | "paused" | "done" | "cancelled" ("paused": a case needs help) auto_fixing — optional bool; when status is "paused" and the Night auto-fix is running, the badge reads "Auto-fixing" failed_count — optional int; when status is "done" and failed_count > 0 the badge reads "Failed" blocked_count — optional int; when status is "done", failed_count is 0 and blocked_count > 0 the badge reads "Blocked". Order: Failed, then Blocked, then Passed — a finished run with blocked cases never reads "Passed". retest_count — optional int; when status is "done", failed_count and blocked_count are 0 and retest_count > 0 the badge reads "Needs re-test". Order: Failed > Blocked > Needs re-test > Passed. {% endcomment %} {% if status == "waiting" %} Draft {% elif status == "started" %} Running {% elif status == "paused" %} {% if auto_fixing %}Auto-fixing{% else %}Needs help{% endif %} {% elif status == "cancelled" %} Cancelled {% elif status == "done" %} {% if failed_count %} Failed {% elif blocked_count %} Blocked {% elif retest_count %} Needs re-test {% else %} Passed {% endif %} {% endif %}
