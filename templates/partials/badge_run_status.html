{% comment %} Status badge for a TestRun. Context contract: status — TestRunStatus value: "waiting" | "started" | "done" | "cancelled" failed_count — optional int; when status is "done" and failed_count > 0 the badge reads "Failed" blocked_count — optional int; when status is "done", failed_count is 0 and blocked_count > 0 the badge reads "Blocked". Order: Failed, then Blocked, then Passed — a finished run with blocked cases never reads "Passed". {% endcomment %} {% if status == "waiting" %} Draft {% elif status == "started" %} Running {% elif status == "cancelled" %} Cancelled {% elif status == "done" %} {% if failed_count %} Failed {% elif blocked_count %} Blocked {% else %} Passed {% endif %} {% endif %}
