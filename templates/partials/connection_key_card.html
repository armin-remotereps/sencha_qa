Connection key

Identifies this project to the Test Runner. A Test Runner already installed for another project can be switched to this one by changing one line in its .env file. 

CONTROLLER_API_KEY=••••••••{{ project.api_key }}

Switch an installed Test Runner to this project

  1. On the test machine, open controller_client/.env.
  2. Replace the CONTROLLER_API_KEY= line with the line above.

    Leave the other lines as they are.

  3. Restart the Test Runner

    Stop it (Ctrl+C in its window) and start it again with the same command as before. It reads .env only at start-up, and an --api-key option or a CONTROLLER_API_KEY environment variable on the test machine takes precedence over it.

A Test Runner connects to one project at a time; the project it leaves shows Not connected. Regenerating the key invalidates the old one, so every Test Runner using it has to be updated with the new line.
