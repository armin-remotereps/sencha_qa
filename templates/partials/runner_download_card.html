Download the Test Runner

The Test Runner is one small Python application that runs on Windows, macOS, and Linux — there is nothing to choose. Download it once, then follow the setup steps for the test machine's operating system below.

ZIP archive, pre-configured for {{ project.name }}. The connection settings are already inside. Already have a Test Runner installed for another project? Switch it with the Connection key card on the Environment page instead of downloading again.

You only download once: this Test Runner and later versions update themselves. When a newer version is available, press Update Test Runner on the Connection card of the Environment page.

ⓘ
Browsers

Chromium, Firefox, and WebKit come with the Test Runner. Google Chrome and Microsoft Edge must be installed normally on the test machine (Edge ships with Windows). Cases run in Chromium unless the test case names a browser, for example “Open the app in Firefox”.

Run python -m controller_client.diagnose --browsers on the test machine to check them.

⚠
Requires Python 3.13 or newer on the test machine.

The setup script checks the version for you and tells you what to install if it is too old.
