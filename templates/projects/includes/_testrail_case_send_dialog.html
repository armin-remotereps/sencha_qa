{% comment %} "Send to TestRail" confirm for failed or Needs re-test cases (case send): checks the cases still unchecked and sends exactly these cases to their source TestRail run now, in any run status except Draft. Follows the dialog convention in templates/partials/README.md; opened by the `open-send-testrail-cases` window event. Not partials/confirm_dialog.html because it posts pivot_ids. Two uses: - Run page (no `pivot`): must sit inside the page's `runCaseChecks` scope. The event's `detail.ids` (a row's Send) are sent, else the selected sendable ids (`toSend`); the selection itself is left unchanged. - Case page (`pivot` given): always sends that one case. Context contract: project — current Project test_run — current TestRun next — where to come back to (validated same-host by the view) next_query — optional query string appended to `next` (the run page's page / per-page) csrf_token — the page's token (the include is rendered with `only`) pivot — optional TestRunTestCase (case page) {% endcomment %}
