Need help: help_panel (projects.case_help_services.HelpPanel, or None unless the run is "paused"): request (latest CaseHelpRequest, case loaded), thread (auto-fix SetupConversation or None), auto_fix_live, blockers, is_open, can_continue_run, waiting_for_auto_fix_stop; request.fault / get_fault_display name the infrastructure fault, "" when the agent asked; the Reason column of that request's case shows it). Drives the paused banner and "Continue run" (projects:test_run_continue). start_form (TestRunStartForm, waiting runs only: the help_mode radio, initial = the run's mode). help_mode_form (RunHelpModeForm: the choices of the help mode select in the Resume / Re-run dialogs, pre-set to the run's mode, and of the header's help mode switch for a running or paused run, which posts to projects:test_run_help_mode). summary also carries need_help. The run WS events carry help_state ("none" | "auto_fixing" | "waiting_for_person"; the context key help_state is the page's baseline) and help_mode (the header switch follows it without a reload); the page reloads when the run moves into or out of "paused" or help_state changes, since the banner is server-rendered. Agent and human text is autoescaped. test_run also carries testrail_source_push_status; testRunLive exposes it as `testrailSourcePushStatus` (WS message "testrail_source_push"). test_run also carries testrail_run_id, testrail_push_status, testrail_pushed_at, testrail_push_error, testrail_push_summary.
