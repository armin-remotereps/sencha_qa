Update the Test Runner to {{ server_version }}?

The Test Runner installs version {{ server_version }} into a new folder next to the current one and downloads its dependencies and browsers there (about 300 MB). This takes a few minutes.

It then restarts from the new folder: the browsers and apps it opened are closed, and the old folder is deleted. Runs and Machine setup on this Test Runner wait until the update finishes.
