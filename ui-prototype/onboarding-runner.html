Connect a test machine

Install the Test Runner on a machine you control so Punk Hazard has somewhere to actually run your tests.

Punk Hazard doesn't run tests in the cloud — it drives a real machine you control, the same way a person would: clicking, typing, and taking screenshots. The Test Runner is a small program you install on that machine so Punk Hazard can connect to it.

Download the Test Runner

The Test Runner is one small Python application that runs on Windows, macOS, and Linux — there is nothing to choose. Download it once, then follow the setup steps for the test machine's operating system below.

⬇ Download Test Runner

ZIP archive, pre-configured for Mobile Checkout. The connection settings are already inside — there is no key to copy.

⚠
Requires Python 3.13 or newer on the test machine.

The setup script checks the version for you and tells you what to install if it is too old.

Set it up

Pick the operating system of the test machine to see the matching commands.

  1. Extract the ZIP and open a terminal in the extracted folder
  2. Run the setup script
    bash controller_client/scripts/setup.sh

    If your default python3 is older than 3.13, point at a newer one:

    bash controller_client/scripts/setup.sh --python python3.13
  3. Start the Test Runner
    controller_client/.venv/bin/python -m controller_client.main
  4. Leave the window open

    The Test Runner has to stay running while tests execute. Its first start also downloads the visual engine, which can take a few minutes.
